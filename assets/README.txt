Game files used by the 3D view and sound (maps, textures, models, sprites, sky, sounds).

To fill this folder, run from the project folder:
    python3 tools/copy_game_files.py "/path/to/Half-Life"
(the folder that contains "cstrike" and "valve")

Then open the player with start.sh (Linux/Mac) or start.bat (Windows).
Expected layout (all lowercase):
    assets/cstrike/maps/de_dust2.bsp
    assets/cstrike/*.wad   assets/valve/*.wad
    assets/cstrike/models/...   assets/cstrike/sprites/...   assets/valve/sprites/...
    assets/cstrike/gfx/env/*.tga   assets/cstrike/sound/...   assets/valve/sound/...
    assets/manifest.json  (generated by the script)

These files belong to Valve: do not distribute them with the project.
